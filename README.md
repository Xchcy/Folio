# Folio · 个人工作记忆助手

Windows 便携版和公开源码的总包使用方法见 [交付说明.md](交付说明.md)。便携版双击 `启动 Folio.cmd`，数据默认位于便携版旁的 `data/`；源码版仍按下文使用 `start.cmd`，数据默认位于 `private/`。

一个在本机运行的中文工作记忆产品。把工作聊天里的决定、事实和承诺组织成可追溯的记录，查看变化、回到原话、纠正候选记忆。

## 启动

安装 Python 3.10 或更新版本后，在此目录运行 `./start.ps1`，浏览器打开 http://127.0.0.1:8765 。启动脚本自动准备项目自己的 `.venv` 并安装 `requirements.txt`，也支持 `./start.ps1 --port 8771`。仅合成演示可直接 `python server.py`。

若旧环境引用的 Python 路径已经失效，启动脚本会保留它，优先复用旁边已安装的 CLI 环境；没有可复用环境时另建 `.venv-recovery`，不删除原环境。需要自定端口或隔离数据时，可使用 `./start.ps1 --port 8775 --data-dir private/preview`。

微信 CLI 源码已内置在 `vendor/wechat_cli`，无需旁边的源码或构建环境，也无需全局 npm 包。微信接入需要 click、pycryptodome、zstandard 三项依赖；项目已初始化的微信配置继续复用。

默认进入合成演示空间。真实会话需要切换左上角「我的本机记录」。不要在公开演示时切换私有空间。

双击 `start.cmd` 也可启动默认端口。开发目录、样式职责和完整检查见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 体验三个问题

选择「社区开放日」：

1. 点击「为什么选这个方案」：看到报名从表格改成独立页面，原因来自修改历史需求，右侧显示原话。
2. 点击「目前确认的时间」：回答 10月19日15:00。10月13日提出的「提前到周五」仍是待确认提议，没有覆盖原记录。
3. 将「回看当时」设置为 2026-10-10，再查时间：返回当时的 10月16日14:00。
4. 清空回看日期，点击「我还有哪些承诺」：「收到」没有被当成完成证据，邀请文案仍在列表里。
5. 找到一条承诺，点击「纠正记忆」，改为已完成并填写说明。保存后查看「修改记录」，原话保持不变。

## 优化版新增体验

选择「发布讨论（合成）」：这是 8 条没有预先标注记忆的合成聊天，经过实际上下文抽取生成候选。能区分本人和小李的两项任务、预算条件、改期和完成表达；「就按刚才说的时间」保留当前回复及被指向上文的共同证据。

「核对后归入此事项」可以批量采用事项建议，原话及记忆确认状态保持不变。后续改期只提示与历史记录可能关联；完成表达不会自动关闭任务。已确认事实与后续不同值会提示核对，人工确认版本关系后才替代旧记录。

在本机记录点击「整理已有聊天」按批次升级旧识别结果（默认每批 200 条，本机模型配置后每批 25 条）。修改过、已确认及已完成记忆不会被覆盖，已有整理版本不会重复运行。

## 模型设置与更换

页面「模型设置」可自行填写兼容 Chat Completions 的接口地址、模型名称和 API Key，随时更换。默认 DeepSeek 官方地址 `https://api.deepseek.com`，示例名称 `deepseek-flash`；以你的服务实际支持的模型为准。地址可为基础地址或完整 `/chat/completions` 地址，外部地址需 HTTPS；API 不兼容 JSON Output 时会提示错误。

「测试合成对话」仅请求一段内置合成改期对话；「用模型整理合成案例」最多调用 8 条固定内置合成消息并更新未人工修改的候选，会使用 API 额度。每项模型结果都需通过结构类型、日期和逐字引用检查，格式通过不代表语义判断一定正确。

Key 只保存在当前服务内存，不写入源码、磁盘或浏览器存储；服务重启后重新填写，或由你在启动环境设置 `MEMORY_API_KEY`。接口地址和模型名称保存到私有数据目录的 `model-config.json`。更改接口地址会清空旧 Key，避免转交给新服务。外部调用不跟随重定向。

**当前外部模型只允许项目内置合成源**，逐字段核对 ID、文本、人物、日期和类型；不能通过给真实消息贴 synthetic 标签绕过。私有空间仍使用本机上下文识别，不会发送真实微信数据。未提供真实 Key 时只验证模拟请求，不宣称远程模型实测通过。

另有可选本机 Ollama 接口：设置 `MEMORY_LOCAL_MODEL` 为已下载的本地模型名称，重启服务后使用固定本机 `127.0.0.1:11434/api/chat`。不支持 cloud 名称或重定向；本机服务尚未实际部署验证。配置错误、输出不合格或服务失败会回退规则并在候选上标明。

接口参考：[DeepSeek 调用](https://api-docs.deepseek.com/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[Ollama 结构化输出](https://docs.ollama.com/capabilities/structured-outputs)。

## 微信读取

点击「从微信选择授权会话」，默认展示本机微信中的联系人和群聊，可搜索昵称、备注、微信ID或群名，跨页勾选新会话后点击「确认授权」。范围来自微信，不限于原先的4个对象；确认仅保存勾选账号的稳定身份，不读取消息。同名账号按尾号区分，不自动合并；重复授权同一账号不会产生重复项。

保存后进入「已授权会话」，本次新选的会话已勾选，点击「读取勾选会话」才读取最近最多400条。也可直接切换该页勾选旧授权，支持全选、清空。空选择、未授权名称、伪造或过期的微信选择票据会被拦截。原「从微信选择导入」保留逐条消息导入，并提供进入会话授权的入口。

「已授权会话」每行有「取消授权」，也可多选后点击「取消勾选授权」。取消立即移出授权读取名单，并使该账号尚未使用的预览及选择票据失效；已导入的原文、记忆与修改历史保留。后续需要读取时，可重新从微信选择并确认授权。此操作不删除微信本身的任何内容。

在工作台点击标题旁「从微信导入」，会自动切换到「我的本机记录」并打开聊天选择窗口。也可从「添加内容」→「导入聊天记录」进入同一流程。

1. 搜索聊天对象的昵称、备注、微信 ID 或群名，点击准确的对象。重名对象按各自身份分别选择。
2. 筛选消息关键词、发送者、开始与结束日期。勾选「只看我发出的消息」，可挑选发给该对象的某一条或几条消息。群聊也可按成员昵称筛选。
3. 每页显示 20 条消息，勾选单条或「选择本页」。使用首页、上一页、下一页、尾页，或输入页码点击跳转；跨页、跨对象的勾选会保留，点击「清空已选」可重选。
4. 点击「导入已选消息」。只保存勾选的原话、引用和来源编号，消息时间自动采用微信数据库原始发送时间，以北京时间显示并保留到秒；原始 Unix 时间同时保留在私有批次中，导入时间和重复导入不会覆盖消息时间。已有消息自动去重。候选记忆仍需人工确认。

关键词、发送者及本人筛选覆盖整个会话，筛选后每页返回最多 20 条消息；日期在数据库层筛选。页码按当前筛选后的实际条数计算，并显示「第几页 / 共几页」。消息从新到旧排列，尾页显示最早记录；无匹配时为 0 页，首页和上一页在第一页禁用，下一页和尾页在最后一页禁用。输入越界页码会提示；数据发生变化导致原页码越界时，服务会跳到新的尾页。

筛选改变时点击「应用筛选」会回到第一页；「清空筛选」一次清除关键词、发送者、日期和只看本人条件。读取检查已知及磁盘上的所有编号消息分库，数据库读取失败会报错，不把失败当作没有记录。筛选总数需要扫描当前会话的匹配范围，大会话可能等待更久。

条数和时间范围仅对应当前微信电脑版的本机消息数据库，不代表历史已完整恢复，也不包括尚未接入的迁移记录库。对照电脑版时请清空筛选，并跳到尾页；仍缺失时需核对具体对象身份、消息日期和当前微信账号。

选择最多 50 个预览批次，预览在内存保留一小时，刷新页面会清空网页勾选。

联系人列表同时显示备注、昵称和账号尾号。同名或同昵称账号保持独立消息编号，不能仅凭姓名推断为同一人。用户明确确认的账号对应关系可以保存在本机 `private/contact-aliases.json`，搜索该人的名字时展示「当前账号」与「旧账号」，并保留微信原备注；原文仍从各自的账号数据库读取，不自动混合或导入。

首次在新电脑使用，登录电脑版微信后在项目目录运行 `.\.venv\Scripts\python.exe wechat_entry.py init` 完成初始化。网页不会自动运行初始化或提取内存；已有 `~/.wechat-cli` 配置可直接复用。只读消息，不发送、不回复、不打印密钥。

「快捷读取已授权会话」保留旧版功能，仅使用本机 `private/allowed-names.json` 名单。不能唯一匹配时跳过并报告，不猜测。

读取通过已有 CLI 的配置、解密和消息格式化模块完成。适配器以只读方式查询解密缓存，用会话身份、数据库名、表名和本地消息编号构成稳定记录 ID；按消息时间和 ID 排序再分页。每次默认读取最近 400 条/会话，开发验证已分页读到 917 条可用记录。可用 Python 调用 `wechat.sync(memory,pages=12)` 扩展窗口。新增消息在后续读取时按 ID 去重。不是持续实时同步，也不读取图片文字或转录语音。

工作记忆 SQLite 数据库、所选原始批次、引用信息和定位信息都在私有数据目录（默认 `private/`，可通过 `--data-dir` 隔离），已排除版本控制。微信 CLI 另复用 `~/.wechat-cli` 配置与密钥，并在系统临时目录 `wechat_cli_cache` 保存本机解密缓存；搜索、预览本身不写入工作记忆库。旧文本指纹试验库保留为 `private/legacy-fingerprint.sqlite3`，正式产品不使用该库。对外提交时必须排除整个 `private/`，仅 `.gitignore` 不等于自动排除压缩包。

## 人工纠错和版本

自动识别的真实内容一律待确认。可调整内容、事项、类型、状态、日期和原因。决定/事实可填写一致的「事实名称」（例如演示时间），选择同事项、同类型、同事实名称且更早的记录作为历史版本。只有已确认的新版本在界面标记旧版。所有修改保存前后快照和说明。

回看日期同时限制来源消息的时间，并回滚日期之后的人工修改，避免后来修改污染历史回答。日期只表示天，暂不提供分钟级回看。

## 当前能力边界

当前默认使用本地上下文规则与中文片段检索，提供可选本机模型和仅限合成数据的外部模型接口。原「社区开放日」演示仍包含预先标注，用于验证版本回看；新增「发布讨论」没有预先标注。事项关联以建议形式呈现，人工采用后归并。尚未实现通用语义向量搜索、开放式模型问答、完全自动跨会话归并或主动提醒；复杂指代仍可能误识别。没有依据时明确无法回答。

引用、图片、文件等保留来源和类型，不作为当前发送者新的承诺。任务完成需要人工确认。应用不把不同发言人的「我」当成本人的承诺。

外部调用仅限用户启用后的内置合成案例。真实聊天外发尚未授权，且没有对应开启入口。当前服务只监听 127.0.0.1，验证 Host 和写请求令牌，不公开托管。具备本机文件访问权限的人仍可读取私有数据；数据库没有加密。

## 验证

运行 `.\.venv\Scripts\python.exe -m unittest -v`（先运行启动脚本安装依赖）。覆盖时间变更、历史回看、提议不覆盖事实、本人承诺、相对日期、完成状态、去重、证据外键、人工修改历史、导入原子性和无证据回答。完整检查运行 `python tools/check.py`，包含前端模块语法、JS 回归与解压交付验证。

运行 `python tools/package_demo.py` 可在 `release/` 生成独立的 `演示源码.zip` 和 `Folio随手记扩展.zip`。打包脚本只包含列出的公开源码和合成数据，排除私有目录、授权名单、真实聊天及调试数据库。演示包解压后可独立启动合成案例；微信接入先运行启动脚本安装依赖，再复用或初始化本人电脑的微信配置，随后在页面选择所需会话和消息。

在 Windows 构建环境安装 PyInstaller 后，运行 `python tools/build_release.py` 可生成便携版、公开源码包和总交付 ZIP。构建脚本使用公开文件清单，不读取 `private/`。交付前应检查 ZIP 内文件，并在解压目录启动便携版验证。

## 结构

`engine.py` 管理存储、候选记忆、人工修改和问答；`extraction.py` 管理上下文事件与日期；`local_model.py` 验证结构与本机模型；`remote_model.py` 管理可更换外部接口及合成白名单；`wechat_bridge.py` 提供结构化只读消息；`wechat.py` 限定身份和分页同步；`server.py` 提供本机页面、配置 API 和后台整理；`web/` 是中文界面；`demo.py` 是纯合成案例。开发记录在 `.planning/development/` 与 `.planning/optimization/`，不随公开源码打包。


### 主页浮动待办
主页右下角区分“待处理”“等别人”“待确认”“提议”“取消”“已完成”。我的承诺与等别人共用工作台的筛选逻辑、状态和修改记录，可折叠、切换空间、查看原话、采用、完成、恢复或忽略。关联日期不等同于截止日期。

“AI 整理待办”复用已配置的模型接口，仅处理内置合成案例；缺少 Key 时打开模型设置。私有空间仅使用已配置的本机模型，未启用时可用“本机整理”进行上下文规则提取。面板区分 AI、本机识别和合成示例，候选仍需人工确认。

新增待办筛选测试：`node --test tests/test_todos.js`。

### 任务核对增量（2026-10-16）

选择合成空间的「任务核对（合成）」可验证我的承诺、等别人、条件性承诺、改期提议和取消表达。执行人归属与确认状态分别显示；原话明确不等于已人工确认，证据不足不允许直接采用为任务。仅表示“等小李回复”不会被解释为小李已经答应。

待确认卡直接展示关键原话、发送者、来源会话和原始发送时间。可一键采用或忽略，也可展开「快捷修改」调整内容、归属、执行人、确定性和日期用途。快捷修改保留确认状态，之后再采用；完整修改保留事项和版本关联入口。主页与工作台共用任务筛选和数据库，已完成也可单独查看。

新抽取区分截止日期、活动时间和一般关联日期。相对日期基于原始消息时间；引用“刚才说的明天”基于被引用消息时间。不会把消息里另一件事的活动日期借给任务，只有明确共同提交的日期才供多个任务共用。本机模型输出的日期也要能由来源及原始时间支持。简单数字时刻可用于同一天改时冲突；含糊时段仍保留待确认。

后续提议不替代既有安排。即使单独采用新时间记录，也需要在「纠正记忆」中明确选择要替代的旧记录后，才切换当前安排；冲突双方原话均可查。取消表达的采用只确认这条记录，不自动关闭此前任务。所有人工修改保留前后快照，重新整理不会覆盖已修改记录。

本轮没有批量重整既有私有库，旧候选可逐条快捷修正，新规则用于新抽取。复杂指代、人员别名和隐含承诺仍可能漏识别；本机模型未部署实测，模型回归使用模拟响应。验证命令：`python -m unittest -q`、`node --test tests/test_todos.js tests/test_extension.js`。在已安装项目依赖的环境运行，新增语义回归位于 `tests/test_ownership.py`。

### 随手记与收集箱

主页使用可交互的书本入口。鼠标悬停时书本轻抬并显示暖色柔光；点击书本或“打开工作记忆”会展开翻页并进入工作台。也可直接进入，键盘 Enter 打开、Esc 取消，系统减少动画设置下直接切换。“最近事项”保留原事项概览；收集箱、模型设置和微信导入收在右上角更多菜单，快捷待办保留在工作台。

收集详情支持“删除这条收集”；列表勾选后支持批量删除和全选当前搜索结果。删除前会确认，内容移入“最近删除”，可单条或批量恢复。删除仅影响收集箱显示，不删除已关联的待办及原文证据。最近删除中的内容保存在本机，没有自动清空或永久删除操作。

主页新增“＋ 随手记”和“收集箱”。支持文字、图片文件、直接粘贴图片、补充说明、来源链接与原始内容时间。收集时间由服务自动记录。内容先保存至本机私有空间，再进行本机 OCR / AI 或规则整理；重启服务后会继续处理未完成记录。

收集箱支持搜索与待办/笔记/资料/灵感/待整理筛选，原文原图可回看，标题、分类、事项、日期类型、日期和识别文字可修正。任务自动成为待确认候选，也可手动转入。重复内容可以追加说明或再次保存。AI 未启用时会明确显示“本机规则”，不会把规则输出冒充模型结果。

Edge / Chrome 右键扩展位于 `extension/`，安装与快捷键说明见 `extension/README.md`。全局快捷键 `Ctrl+Shift+9` 打开粘贴小窗，页面内快捷键为 `Alt+Shift+M`。扩展需手动加载至自己的浏览器；网页应用自身不能修改浏览器原生右键菜单。

新增验证：`python -m unittest tests.test_capture tests.test_api -v`、`node --test tests/test_extension.js tests/test_todos.js`。OCR 可用性和识别结果依赖本机 Windows 语言组件；识别不成功不影响原图保存。
